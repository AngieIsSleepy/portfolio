[Under Development]Dual Prediction System 【开发中】基于社媒内容的心理健康检索系统

This is a lightweight, non-clinical NLP information retrieval framework designed to bridge the "semantic gap" in mental health support.

  • Instead of relying on rigid keyword searches, it makes predictions based on users' natural expressions.
  • The system simultaneously predicts a user's potential mental health problems (e.g., anxiety, burnout) and their MBTI-based personality.
  • By prioritizing context and personal coping styles, it delivers more empathetic support without attempting clinical diagnosis.

本项目是一个轻量级的非临床 NLP 信息检索框架，旨在消除心理健康支持中常见的语义误差。

  • 模型通过检索抓取关键词，分析用户的评论、帖子，判断潜在的心理问题以及性格特点。
  • 理解文本时，它会同时预测用户的心理困扰（如焦虑、抑郁倾向）以及基于 MBTI 的简单性格分析。
  • 通过结合语境与个人风格，系统能在不进行临床诊断的前提下，提供更具同理心、更切实可行的建议与支持。

[Under Development]VeroEat: AI-Driven Food Safety App 【开发中】VeroEat：AI 驱动的食品安全助手

A mobile application built with Expo (React Native) and Jac, focusing on personalized allergen detection and food recall tracking.

  • Intelligent Scanning: Integrated OpenFoodFacts API to fetch real-time ingredient data and cross-reference it with user-defined allergy profiles.
  • AI Recommendation Engine: Implemented a Jac-based backend that leverages LLMs to provide safe, alternative product suggestions when allergens are detected.
  • State Management: Developed complex profile switching logic and a virtual inventory system to track scan history and product safety.

一个基于 Expo (React Native) 和 Jac 语言开发的手机应用，专注于个性化过敏原检测与食品召回追踪。

  • 智能扫描分析： 集成 OpenFoodFacts API 获取实时成分数据，并与用户自定义的过敏原档案进行匹配。
  • AI 推荐引擎： 在 Jac 后端 中集成大语言模型 (LLM)，当检测到有害成分时，自动为用户提供健康、安全的替代品建议。
  • 复杂状态管理： 设计并实现了多用户切换逻辑及虚拟库存系统，持久化存储用户的扫描历史与安全反馈。

* Currently under active development. More UI updates coming soon! * 正在开发中，界面与功能仍在持续迭代完善。

Legend of Zelda - Rebuild 塞尔达传说 - 1986年初代重制版

A recreation of the classic NES Legend of Zelda Eagle Dungeon, developed using Unity Engine. This project served as my introduction to game engine mechanics and level design.

  • Level Construction & Logic: Built the dungeon scenes and programmed core interactive systems, including enemy spawn points, reward pickups, and door-unlocking triggers under different conditions.
  • Audio-Visual Polish: Responsible for embedding sound effects, as well as programming the smooth room transition.
  • Custom Puzzle Mechanics: Designed and implemented a unique "Ice Gun" feature. Players can freeze enemies into pushable ice blocks. I also engineered the puzzle logic requiring multiple pressure plates to be activated simultaneously by these blocks to unlock specific doors.

基于 Unity 和 C# 开发的《塞尔达传说》初代神鹰迷宫重制版。这是我的首个游戏项目，全面锻炼了我的场景搭建与脚本编写能力。

  • 关卡搭建与交互逻辑： 负责核心场景的搭建与系统编写，包括可复用的敌人生成点、奖励拾取逻辑，以及普通房间与特殊隐藏房间的开门触发条件设置。
  • 视听体验优化： 编写了平滑的房间切换动画逻辑，并负责了全流程音效的镶嵌与触发管理。

Another Me Another Me

My first fully independent game project: a narrative-driven 2D puzzle platformer. Featuring a minimalist hand-drawn pixel art style, all visual assets, mechanics, and level designs were created entirely by myself.

  • Core Mechanic: Designed and programmed a system where players must coordinate two characters simultaneously to navigate through the levels.
  • Level & Puzzle Design: Built various interactive puzzles utilizing the mirror mechanic, such as cooperative door-opening, shooting water drops to activate remote triggers, and using portals to redirect water trajectories.
  • Art & Narrative: Crafted all pixel art assets. The minimalist aesthetic perfectly serves the emotional narrative of two hearts overcoming obstacles to unite.

独立制作游戏：一款叙事驱动的 2D 横版解谜平台游戏。采用极简的手绘像素风格，所有代码逻辑、关卡设计与视觉美术均由我个人独立完成。

  • 核心“镜像”机制： 设计并编写了双控系统，玩家需要左右脑互相配合，同时控制两个角色来突破关卡障碍。
  • 关卡与交互设计： 结合镜像机制设计了丰富的解谜要素，例如互相协助触发机关开门、发射水滴激活远距离机关、以及利用传送门改变落点等复合逻辑。
  • 美术与叙事表达： 独立绘制所有的像素美术，极简手绘风格帮助服务于情感叙事。

* Planning to update the game with more polished art and mechanics soon. * 此项目后续将进一步打磨美术表现与玩法细节。

[Under Development]Bargain Brawl! [开发中]超市大采Go！

A fast-paced, competitive split-screen party game. Set in a colorful supermarket, players take turns to checked out required items. Use different items to speed up, create foggy zones, and spill liquid on the ground! Think carefully and find your way in this chaotic store!

  • Split-Screen Gameplay: Architected and programmed a robust split-screen UI system. It dynamically manages two independent perspectives, providing instant visual feedback for both players.
  • Game Rules: Designed the main gameplay loop: in each round, one collector needs to checkout required items, and the defender needs to try everything to block. The one using less time wins the round.
  • Various Item Abilities: Created different items' special abilities, including creating spills that slow players down, eatable food that scales the players, and the melee items that can hit the rival. Multiple item usage adds surprising interactions and more possibilities to the gaming experience.

一款目前正在积极开发中的快节奏、竞技型派对游戏。 在一个超市里，玩家需要竞速占领共享 Bingo 计分板 上的物品， 仔细思考策略，使用不同的物品道具增幅自己或是阻挠对手吧！

  • 同步分屏和视角： 编写了分屏 UI 系统。该系统可动态管理两个独立的玩家视角，同时确保一个共享的 Bingo 计分板实时更新，为两名玩家提供即时的视觉反馈。
  • 事件驱动物品收集： 设计了一个可扩展的 事件驱动架构， 将物理游戏世界与游戏逻辑相连接。 此系统可可靠地处理来自超市结账台的“物品结账”事件，直接触发 Bingo 格子的占领和分数计算。
  • 计分逻辑： 实现了核心的 博弈竞技规则。 系统可自动追踪 25 种独特物品、已被占领的格子，计算得分，从而实现诸如阻碍对手以统治计分板等复杂的游戏逻辑。
